# Facebook-группы недвижимости (источник для пересылки)

Автоматический парсинг этих групп **не делается**: у Facebook нет публичного API для
чтения постов групп, доступ за логин-стеной, а обход детекции и массовый сбор чужих
персональных постов нарушают правила Facebook и рискуют баном аккаунта.

Легальный путь: пользователь — участник этих групп. Увидев подходящий пост,
он **пересылает его боту** (или `/add <текст>`), и бот разбирает цену, район,
площадь, комнаты, этаж и добавляет объявление в каталог (source = `facebook`).
См. `src/forwarded.js`.
