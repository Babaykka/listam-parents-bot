# Telegram List.am Real Estate Bot

Бот проверяет новые объявления List.am по квартирам и домам, сохраняет уже виденные `item id` и отправляет новые совпадения всем подписчикам Telegram-бота. В обычном режиме скан идет каждые 5 минут; если List.am отдаёт страницу проверки, бот временно переходит в бережный режим с более длинной паузой.

Он не пытается обходить защиту сайта. Если List.am показывает обычную страницу проверки при локальном запуске, запусти с `LISTAM_SHOW_BROWSER=true LISTAM_PAGE_WAIT_SECONDS=180`, пройди проверку в открывшемся окне, затем оставь монитор работать.

## Настройка

1. Создай Telegram-бота через `@BotFather` и получи token.
2. Скопируй `.env.example` в `.env` и заполни `TELEGRAM_BOT_TOKEN`.
3. Запусти бот.
4. Каждый получатель должен написать боту `/start`.
5. Для семейной группы добавь бота в группу и отправь `/start` прямо в группе.

```bash
cp .env.example .env
```

## Команды пользователей

- `/start` - включить подписку и показать короткое объяснение
- `/tour` - заново показать объяснение для новичка
- `/stop` - выключить подписку
- `/latest` - последние найденные варианты
- `/top` - лучшие варианты по качеству
- `/houses` - последние дома по текущим фильтрам
- `/apartments` - последние квартиры по текущим фильтрам
- `/test` - проверить, что Telegram-доставка работает
- `/scan` - запустить внеочередной скан с cooldown
- `/filters` - мои фильтры
- обычный текст в личке - бот ответит на вопросы о себе или предложит фильтры и попросит подтвердить
- `/ai 2-3 комнаты до 110к, Avan или Nor Nork` - настроить фильтры текстом
- `/apply` - применить предложенные фильтры
- `/cancel` - отменить предложенные фильтры
- `/setup` - быстрые пресеты
- `/preset ready` - больше готовых к жизни вариантов
- `/preset value` - искать выгодную цену за м²
- `/price 80000-120000` - диапазон цены
- `/budget 100000` - цена до суммы
- `/rooms 2-3` - комнаты
- `/area 50-100` - площадь
- `/land 100-600` - участок для домов
- `/sqm 1600` - цена за м² до суммы
- `/floor 1-4` - этаж
- `/distance 25` - минут до центра
- `/elevator yes` - только с лифтом
- `/condition ready` - с ремонтом
- `/keywords gas, balcony` - обязательные слова
- `/exclude agency` - исключить слова
- `/score 6` - минимальное качество 0-10
- `/areas Avan, Nor Nork, Abovyan` - выбрать районы
- `/areas all` - снова все районы
- `/types apartment, house` - типы жилья
- `/reset` - сбросить фильтры
- `/share` - ссылка, чтобы передать бота

## Локальный запуск

Проверить health endpoint:

```bash
DRY_RUN=true SCAN_ON_START=false ./run_telegram_monitor.sh
```

Постоянный запуск:

```bash
./run_telegram_monitor.sh
```

## Render deploy

Рекомендованный вариант - Render Web Service на Docker runtime с persistent disk. `render.yaml` уже добавлен.

Нужно:

1. Залогиниться в Render CLI: `render login`
2. Запушить этот проект в GitHub/GitLab/Bitbucket.
3. Открыть Blueprint в Render Dashboard и заполнить secret `TELEGRAM_BOT_TOKEN`.
4. После деплоя открыть Telegram-бота и отправить `/start`.

Если Render не выставил внешний URL автоматически, добавь env var `PUBLIC_URL=https://your-service.onrender.com`.

## Health

`GET /health` возвращает статус сервиса, подписчиков, последний скан, следующий скан, текущий режим расписания и состояние сканера. Если List.am несколько раз подряд отдаёт страницу проверки вместо объявлений, бот покажет это в `/status` и предупредит подписчиков.

## Тесты

Перед деплоем можно прогнать безопасные локальные проверки. Они используют fake Telegram и не отправляют сообщения реальным пользователям.

```bash
npm test
```

Отдельные проверки:

```bash
npm run test:full
npm run test:stress
```

`test:full` проходит основные команды, фильтры, сохранённые объявления, ручной скан и уведомления. `test:stress` имитирует сотни пользователей, много новых объявлений и ошибки доставки Telegram.

## Где хранятся данные локально

- `data/listam-bot-state.json` - уже виденные объявления, подписчики Telegram-бота и offset Telegram updates.
- `data/listam-browser-profile/` - локальный профиль браузера для обычных cookies/session.

В проде Render хранит аналогичные данные на persistent disk `/var/data`.
